# الخطة التنفيذية — 4 مراحل

## المرحلة 1 — تحليل المرجع وتأسيس مشروع قابل للبناء
- ✅ تحليل APKS الحقيقي وتوثيق الحزمة والشاشات والوظائف الظاهرة من الأدلة العامة.
- ✅ إعداد مشروع Native Android مع هيكل ملفات وذاكرة واستعادة وGitHub Actions.
- ✅ تأكيد نجاح Gradle ووجود Artifact APK في التشغيل 42498105704، مع إصدار تجريبي قابل للتنزيل.
**معيار الإغلاق:** workflow ناجح، APK قابل للتنزيل مع SHA، بدون أخطاء Manifest/Java.

## المرحلة 2 — المطابقة الوظيفية والواجهة
- 1–20 WebViews متزامنة داخل Activity واحدة.
- تخطيطات Grid وVertical Stack وHorizontal Strip وSingle Focus؛ ترتيب وحذف وإضافة وتعديل URL وsame-URL/multi-URL.
- عناصر التصفح لكل نافذة: رجوع، تقدم، تحديث، عنوان، Desktop UA، تنزيل، رفع ملف، لقطة شاشة.
- واجهة slate-blue جميلة، وضع فاتح/داكن، متوافقة مع هواتف صغيرة وأجهزة لوحية، وتراعي مناطق النظام.
- حفظ التخطيط والصفحات والمفضلة وسجل الزيارات.
**معيار الإغلاق:** تجربة بشرية على الهاتف مع صور شاشة تُظهر المطابقة، وتوثيق النواقص الحقيقية.

## المرحلة 3 — الثبات والصفحات الطويلة
- احتفاظ WebViews حيّة عند تبديل التخطيط وعدم recreate بلا حاجة؛ لا auto reload افتراضياً.
- معالجة WebView renderer termination وlow-memory وrestoration بشكل صريح.
- تحسين 5 صفحات مرئية و10–20 جلسة، وضبط عدد الإطارات المؤقتة والذاكرة.
- تصميم آمن لوضع Private profile منفصل؛ تجنّب الادعاء بعزل الكوكيز لكل pane.
- اختبارات ChatGPT: تسجيل الدخول، نسخ/لصق، رفع الصور، تمرير المحادثات الطويلة، تبديل العرض وترك التطبيق والعودة.
**معيار الإغلاق:** نتائج جهاز فعلية لعدة أحمال مع نسب reload وRAM موثقة، بدون وعود غير ممكنة على Android.

## المرحلة 4 — إصدار قابل للتثبيت وتوثيق
- اختبار portrait/landscape, Android 15, screen insets, keyboard, accessibility.
- اختبارات offline/error/slow net, browser security, downloads, process recreation.
- GitHub Release/APK موقع بتوقيع ثابت عند توفر مفاتيح آمنة؛ عدم وضع private signing key في repo عام.
- ملفات استعادة محدثة، تعليمات تثبيت واضحة، وباك لوج إصلاحات.

## قرارات
- Java + Android WebView، Gradle + Actions، بدون Root وبدون الاعتماد على REA/Craft في APK النهائي.
- مفتاح التخطيط: لا destroy/reload لـ WebViews إلا عند إغلاق النافذة صراحة أو قتل النظام للعملية.
- 20 نافذة ليست وعداً بأداء متساوٍ؛ استهلاك RAM والتزامن وسياسة Chromium محددات على الجهاز.
- اختلاف التصميم عن العلامة التجارية الأصلية مقصود، والوظائف المطابقة هي الهدف.
