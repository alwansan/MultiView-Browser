# هوية MultiView Browser البصرية

اعتمدنا هوية مستقلة مبنية على **أربع نوافذ متصفح** داخل دائرة/شبكة مرئية، مع نافذة أولى سماوية للدلالة على الصفحة النشطة. ألوان الهوية:

| العنصر | الرمز |
|---|---|
| الخلفية الداكنة | `#071225` |
| سطح البطاقات | `#0E2948` |
| السماوي | `#39E5EF` |
| الأزرق | `#4E90FF` |
| لمسة ذهبية | `#FFCE59` |

رسومات المستودع SVG أصلية (توضح *فكرة* التطبيق). لا يجوز عرضها بصفتها لقطات حقيقية من شاشة التشغيل. نسخة التطبيق تستخدم Android Adaptive Icons بأبعاد 108dp مع مساحة آمنة للرمز في المنتصف وفق [إرشادات أندرويد](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

يمكن التبديل بين النسختين من README عن طريق الروابط `README.md` و`README.ar.md`. GitHub README لا يوفر زر تبديل لغة تفاعلياً؛ الروابط العادية حل متوافق وموثوق.

ما يزال مطلوباً التقاط screenshots حقيقية من النسخة المثبتة على الهاتف، مع حجب الحسابات والمحادثات الخاصة. ليس هناك حاجة لتغيير الأيقونة أو تصميم الواجهة من الصفر عند كل تحديث.
