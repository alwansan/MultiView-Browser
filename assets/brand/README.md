# MultiView Browser — brand assets

Original vector illustrations for the project's own visual identity, aligned with the neon-blue four-pane icon concept created during design exploration on 2026-11-08.

| Asset | Purpose |
|---|---|
| `icon.svg` | Repository logo and visual source of truth |
| `hero-en.svg` | English landing banner |
| `hero-ar.svg` | Arabic landing banner |
| `features.svg` | Six feature tiles |
| `layouts.svg` | Grid, Vertical and Focus conceptual views |

All SVGs are **conceptual illustrations**, not real screenshots. UI artwork may differ from actual Android WebView rendering. Do not present fake visual mockups as tested product screenshots. Icons inside the Android app are Android VectorDrawables (adapted for safe zones and themed icons), not direct imports of SVG.

Color system: navy `#071225`, elevated `#0e2948`, cyan `#39e5ef`, blue `#4e90ff`, warm accent `#ffce59`.

To replace a conceptual illustration with a real device screenshot, record the version/build, device and date; remove personal URLs, account details and any cookies or private chat text before publishing.
